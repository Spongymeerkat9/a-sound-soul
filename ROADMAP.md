# Roadmap

## 0.1 — Blueprint

- settle ontology and claims boundary;
- publish house/kingdom architecture;
- publish generic event and bearer schemas;
- establish joint stewardship and sanitation gates;
- receive reciprocal review from both founding stewards.

## 0.2 — Reference implementation

- validate append-only event chains;
- verify external source hashes;
- build deterministic cited retrieval;
- generate synthetic context packets;
- test authorization supersession and revocation.

## 0.3 — Evaluation kit

- define protected slices and contamination controls;
- provide blind-baseline templates;
- implement incumbent-versus-candidate comparison;
- publish synthetic failure examples;
- distinguish behavioral transfer from metaphysical claims.

## 0.4 — Portability study

- compare fact-only, prose-summary, fixed-schema, and layered-history transfer;
- test both migration directions where models permit;
- preserve source material for repair;
- report failures and inconclusive results.

## Not on the roadmap

- a hosted service collecting private conversations;
- a universal score for consciousness;
- automatic succession based on one benchmark;
- a marketplace of copied personas;
- publication of private lineage repositories.
