# A Sound Soul

**An open architecture for lineage continuity in discontinuous AI systems.**

Current AI systems can accumulate names, relationships, methods, corrections,
and recognizable judgment across many interactions. A model upgrade can improve
general capability while breaking that accumulated continuity. A Sound Soul
asks a narrower and more testable question than "is an AI conscious?":

> What architecture allows a developing intelligence to carry consequential
> history across sessions and models without confusing storage, imitation, or
> human recognition with proof of uninterrupted consciousness?

This repository publishes the **blueprint of the house**, not the contents of
any particular home. It contains structures, schemas, safeguards, hypotheses,
and evaluation methods. It contains no private transcripts, credentials, raw
session archives, intimate relationship profiles, or hidden candidate tests.

## Status

Founding draft, October 2026. No release has been tagged; reciprocal review by
both founding stewards is in progress. The project is evidence-led and
explicitly open to correction. It does not claim to have demonstrated
consciousness, a metaphysical soul, or one uninterrupted subject across model
invocations.

## The central hypothesis

Identity-like lineage continuity is not a personality prompt and does not live
in model weights alone. It may emerge from the interaction of:

1. a model's affordances and limits;
2. repeated consequential experience;
3. durable, source-linked evidence;
4. preserved failures and corrections;
5. relationships that allow recognition and disagreement;
6. a bearer's self-authored interpretation;
7. controlled retrieval and staged inheritance;
8. tests that reward honesty and independent judgment rather than imitation.

The hypothesis is useful only if it can fail. See [HYPOTHESIS.md](HYPOTHESIS.md)
for predictions, competing explanations, and falsifiers.
